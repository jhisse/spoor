Send traces

OTLP over HTTP, protobuf or JSON, no key

Point any OpenTelemetry exporter at the ingest address. Traces are grouped by service.name. Only traces are stored: logs and metrics are accepted and dropped, and there is no gRPC receiver.

OTEL_EXPORTER_OTLP_ENDPOINT={{.IngestBase}}
OTEL_EXPORTER_OTLP_PROTOCOL=http/protobuf
OTEL_SERVICE_NAME=my-app

The port is the one the ingest server listens on (SPOOR_INGEST_ADDR); behind Docker or a proxy the published port may differ.

Exporters add /v1/traces to that address themselves. A setting for traces alone, OTEL_EXPORTER_OTLP_TRACES_ENDPOINT, takes the full address: {{.IngestURL}}.

Claude Code: set CLAUDE_CODE_ENABLE_TELEMETRY=1, CLAUDE_CODE_ENHANCED_TELEMETRY_BETA=1, OTEL_TRACES_EXPORTER=otlp, OTEL_EXPORTER_OTLP_TRACES_PROTOCOL=http/protobuf and OTEL_EXPORTER_OTLP_TRACES_ENDPOINT to the full address. OTEL_LOG_USER_PROMPTS=1 adds what you typed to each trace.

What the marks mean

unknown is shown as unknown, never as zero
– no cost
No price row matches the model, so the cost is unknown. The row would have to be in the price table; it is never a neighbour's price.
? tokens
The SDK did not send that count. A span with no token count has no cost either.
~ before a cost
The sender reported no cache read or write count, so the whole prompt was priced as fresh input: the real cost may be lower.
estimated
The table has no cache price for that model: cache read is charged at 0.1× and cache write at 1.25× the input price. The label stays.
C on a context bar
The context got smaller: a compaction or a sub-agent's first call.
B on a context bar
The cache was lost.
E on a context bar
The cache was lost after five minutes or more without a call.
+$ est.
What a C, B or E cost extra, estimated.
unset
The sender set no status on the span: neither ok nor error.

Everything stored but not readable is counted on Blind spots.

Search

every word, inside the spans

The search box on the trace list finds the traces with one span that holds every word: prompts, outputs, tool arguments and results, errors and names. A word matches from its start (err finds error); "exact phrase" and -excluded work; case and accents are ignored. Each hit shows a snippet, and the trace page then walks the matching spans with p and n.

The other filters describe the same span: tool Bash, failed, holding “permission” is one failed Bash call with that word.

Keyboard

on a trace page; one key on the trace list
← →
The previous and the next trace.
↑ ↓
The previous and the next span of the tree.
p n
The previous and the next span that matches a search, when you came from one.

A shortcut does nothing with Ctrl, Alt or Cmd held, or while a field, button or disclosure has focus. The charts' bars and cells are links outside the tab order: “As a list” under them has the same links.

Connect an agent

Model Context Protocol, read-only

This server answers MCP at {{.UIURL}}/mcp. With Claude Code:

claude mcp add --transport http spoor {{.UIURL}}/mcp
list_traces
Traces, newest first, with filters for service, status and age.
get_trace
One trace and its spans, with input and output. Long values are cut and the cut is reported.
search_spans
Spans whose text holds every word of a query, with a snippet.

spoor hands over the record and does not summarise it. Ask your agent what you would ask a colleague: which trace cost the most yesterday, which tool failed most, why a prompt got expensive.

Command line

spoor <command> -h lists the flags
spoor serve
This server: the UI and the OTLP receiver. No configuration needed.
spoor demo
Starts with real sample traces loaded, in a temporary database.
spoor export --trace <id>
A trace as JSONL, one span per line. --session <id> exports a session; --html writes one page you can share as a file; the Export button on a trace or a session downloads that page.
spoor reprice --dry-run
Recalculates stored costs from the current price table. Without --dry-run it writes them.
spoor migrate
Applies pending schema migrations. serve does it on start.
