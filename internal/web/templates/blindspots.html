Blind spots

What is stored but cannot be read, and what never reached storage. Counted, never guessed.

Stored, not read

{{commas .Traces}} traces · {{commas .Spans}} spans · {{commas .Generations}} model calls
Traces without a root
{{commas .Rootless}}
every span names a parent that never arrived; a coding agent exports its root last, so a running turn looks like this. The list marks them.
Spans without their parent
{{commas .Orphans}}
shown as roots, marked “no parent”.
Model calls without a token count
{{commas .NoInputTokens}}
the SDK sent none; tokens show as “?” and the cost is unknown. Failed calls are not counted: they have none to send.
Model calls without a model
{{commas .NoModel}}
no price can match; the cost is unknown.
Model calls without a price
{{commas .UnpricedSpans}}
the model matches no row of the model_prices table; the cost is unknown (–), never a default.
Costs priced without cache counts
{{commas .CacheUnknown}}
the SDK sent no cache read or write count, so the whole prompt was priced as fresh input; marked “~”.
Prompts not readable as messages
{{commas .NoMessages}}
stored and shown as sent; no comparison with the previous call.

Where prices come from. The table is seeded from Langfuse's public price list; a cost the sender reports itself is used as is.

Estimated cache cost. When the table has no cache price for a model, cache read is charged at 0.1× and cache write at 1.25× the input price, and the figure is labelled “estimated”.
